The user selected the open book with a golden star logo for Claude Code to integrate.

Files in this folder:
- little-light-logo.png: transparent horizontal icon + lowercase "little light" wordmark, 1440 × 520 pixels.
- little-light-icon.png: transparent original icon without lettering. Use for icon-only placements; it contains transparent padding.
- little-light-preview.png: cream-background presentation preview, not the production transparent logo.

Wordmark colour: dark plum #2b2250. The icon uses amber/gold, cream pages, teal and plum.
Keep the image proportions; do not stretch. Crop transparent padding as needed for header placement. Use accessible alt text "Little Light" for the home logo link. Check legibility at actual mobile header sizes. A simplified small-size icon should be made before using this glossy illustration as a tiny favicon.

These PNGs are raster concept assets, not SVG/vector masters. The website has NOT been updated to use this logo. Original concept files remain in assets/brand/concepts/. The existing site and uncommitted scenery work should be preserved when integrating the logo.
