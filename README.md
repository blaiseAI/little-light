# Little Light

Five-minute Bible stories and games for kids aged 5 to 7, made with Sabbath-keeping families in mind.
Each story opens with picture pages read aloud, then a short quiz: pick the answer, match the pairs,
and build the memory verse. Every finished story lights a star; each week is a constellation of seven
stars, one for each day of creation week.

Plain HTML, CSS and JavaScript. No framework and no build step for development: open `index.html`.

## What's where

| Path | What it is |
| --- | --- |
| `index.html` | Page structure and all drawings (SVG symbols) |
| `styles.css` | Design system: tokens, ink-outlined "sticker" components, layout |
| `app.js` | Game logic: night sky, lessons, story time, sound effects, narration |
| `stories/week-N.js` | Story content, one file per week (data only) |
| `audio/` | Narration in Kokoro "Heart", generated by `tools/record.mjs`. Never edit by hand |
| `tools/` | Recording, checking and publishing tools |

## Content rules

- Story pages are simple retellings in plain words. Anything in `quote` is **NIV, word for word**,
  checked against Bible Gateway, with its reference in `qref`.
- The footer carries the NIV copyright notice Biblica requires.
- Have a Sabbath-keeping parent or teacher read new stories before they go out.

## Adding or editing a story

1. Edit `stories/week-N.js` (a new week: add `stories/week-N.js` and a `<script>` tag in `index.html`).
2. `node tools/record.mjs` records only the clips whose words changed (`--dry` to preview, `--prune` to delete unused clips).
3. `node tools/check.mjs` plays every story in Chrome and checks every clip loads. It must say `CHECK PASSED`.
4. `node tools/build.mjs` writes `dist/` for publishing.

## Recording narration: one-time setup

Needs Python 3.10+, ffmpeg, and the Kokoro model (downloaded once by HyperFrames):

```
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install kokoro-onnx soundfile
npx hyperframes tts "hello"        # downloads the model to ~/.cache/hyperframes/tts
npm install                        # Playwright for tools/check.mjs (uses your installed Chrome)
```

## Scenery assets

The home scene keeps Pip in SVG and loads two transparent scenery layers (distant hills and moon) from
`assets/scene/phone` (up to 640 CSS pixels) or `assets/scene/desktop`.
Both load together before replacing the inline fallback hills. The scene
retains its original drawing if an image cannot load, including without JavaScript.
Pause motion and the system reduced-motion preference stop layer movement.

Unmodified ImageGen originals and generation prompts are in `assets/raw`.
To rebuild the cropped, exact-palette PNGs, install Pillow and NumPy in the local
Python environment and run `python tools/prepare_scenery.py`.
`assets/scene/manifest.json` records sizes, palette, crops, and byte totals.
The build copies only optimized scenery into `dist/assets/scene`.

The revised welcome shares Pip's character geometry with lessons, but places a
separate lantern on the ground. Pip, the lantern, the path and contact marks are
stationary. Only the distant hills move during sunset. The other generated layers
remain in the asset library but are not loaded on the homepage.
